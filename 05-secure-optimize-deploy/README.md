# Domain 2 — Secure, Optimize and Deploy Database Solutions (35–40%)

This domain turns a working database into a **production-ready** one: secure, fast, deployed automatically, and integrated with Azure services.

## Prerequisites

- Domain 1 completed (especially programmability objects and indexes).
- *Azure SQL Platform → Connecting and Authenticating*.

## Chapters and the objectives they cover

| # | Chapter | Official objective |
|---|---|---|
| 1 | [Data Security and Compliance](01-data-security.md) | Encryption, Dynamic Data Masking, RLS, object permissions, passwordless access, auditing |
| 2 | [Securing Endpoints and Identities](02-securing-endpoints.md) | Managed Identity for model endpoints; securing GraphQL, REST and MCP endpoints |
| 3 | [Transactions and Concurrency](03-transactions-and-concurrency.md) | Isolation levels and concurrency controls |
| 4 | [Query Performance](04-query-performance.md) | Configurations; execution plans, DMVs, Query Store, Query Performance Insight; blocking and deadlocks |
| 5 | [SQL Database Projects and CI/CD](05-sql-database-projects-cicd.md) | Implement CI/CD by using SQL Database Projects |
| 6 | [Data API Builder](06-data-api-builder.md) | DAB configuration, REST/GraphQL entities and endpoints, deployment |
| 7 | [Monitoring and Change Handling](07-monitoring-and-change-handling.md) | Azure Monitor; CES, CDC, Change Tracking, Azure Functions SQL trigger, Logic Apps |

## Matching labs

- **Lab 3** — Security
- **Lab 4** — Performance
- **Lab 8** — Data API builder and SQL Database Projects
