# Foundations

This space teaches the ideas that **every other chapter assumes you know**. There is very little code here — the goal is understanding.

## Chapters

1. [What Is a Database?](what-is-a-database.md) — data, tables, rows, columns, and what a DBMS does for you
2. [The Relational Model and Keys](relational-model-and-keys.md) — primary keys, foreign keys, relationships, normalization
3. [Cloud Concepts for Database Developers](cloud-concepts.md) — IaaS/PaaS/SaaS, regions, identity, cost

## Learning outcomes

After this space you can:

- Explain what a table, row, column, and data type are.
- Identify the primary key and foreign keys in a simple design.
- Explain why we split data into related tables (normalization).
- Describe the difference between IaaS, PaaS and SaaS, and where SQL Server, Azure SQL and Fabric fit.
- Explain what Microsoft Entra ID is and why it matters for database security.
