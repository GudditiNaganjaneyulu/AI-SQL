# Welcome — Start Here

This guide takes you from **zero database knowledge** to being ready for **Exam DP-800: Developing AI-Enabled Database Solutions**.

It is written for a complete beginner. Every chapter assumes only what earlier chapters taught you, so **read it in order** the first time.

## How this guide is organized

| Stage | Space | What you learn | Why it comes here |
|---|---|---|---|
| 0 | **Start Here** (you are here) | The exam, the roadmap, and your tools | You need a plan and a working environment first |
| 1 | **Foundations** | What databases are, the relational model, cloud basics | Every later topic uses these words |
| 2 | **Core T-SQL** | Writing queries: SELECT, joins, grouping, subqueries, changing data | The exam assumes you can already write T-SQL |
| 3 | **Azure SQL Platform** | SQL Server, Azure SQL, and SQL database in Fabric — when to use which | The exam covers all three platforms |
| 4 | **Domain 1 — Design & Develop** | Tables, indexes, JSON, programmability, advanced T-SQL, AI-assisted tools | 35–40% of the exam |
| 5 | **Domain 2 — Secure, Optimize & Deploy** | Security, performance, CI/CD, Data API builder, change tracking | 35–40% of the exam |
| 6 | **Domain 3 — AI Capabilities** | Embeddings, vector search, hybrid search, RAG | 25–30% of the exam; needs everything before it |
| 7 | **Hands-on Labs** | Guided exercises you run yourself | Understanding comes from doing |
| 8 | **Revision & Practice** | Cheat sheet, knowledge checks, practice exam, checklist | Final preparation |

## How to use each chapter

1. **Read the "Why this matters" box first.** It tells you what problem the feature solves.
2. **Type the examples yourself** — don't copy-paste. Typing builds memory.
3. **Do the "Try it" exercise** at the end of the chapter before moving on.
4. **Answer the knowledge check.** If you get less than 80%, re-read the chapter.
5. After each stage, do the matching lab in **Hands-on Labs**.

## Conventions used

- `code in this style` is something you type or a name in the database.
- **Exam tip** boxes call out things that are frequently tested.
- **Preview** marks features that are still in preview on at least one platform. The exam *may* include preview features that are commonly used.
- Examples use the **T-SQL** dialect (Microsoft SQL Server / Azure SQL). Other databases such as PostgreSQL or MySQL use different syntax in many places.
