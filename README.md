# DP-800 Study Guide — Developing AI-Enabled Database Solutions

A beginner-to-exam-ready learning path for **Microsoft Exam DP-800: Developing AI-Enabled Database Solutions**, written in T-SQL for SQL Server 2025, Azure SQL, and SQL database in Microsoft Fabric.

Aligned to the official skills outline **as of October 19, 2026** — always confirm against the [official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-800).
