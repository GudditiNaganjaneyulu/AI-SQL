# Domain 1 — Design and Develop Database Solutions (35–40%)

The largest exam domain. It turns your Core T-SQL skills into **database design** and **professional T-SQL development**.

## Prerequisites

- Foundations and Core T-SQL spaces completed.
- Lab database from **Lab 0** created.
