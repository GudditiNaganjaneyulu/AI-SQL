# Azure SQL Platform

DP-800 covers **three platforms that share one engine**: SQL Server, Azure SQL, and SQL database in Microsoft Fabric. This space explains what each is, when to choose it, and how to connect securely.

## Chapters

1. [The SQL Platform Family](sql-platform-family.md)
2. [Purchasing Models and Service Tiers](purchasing-models-and-tiers.md)
3. [Connecting and Authenticating](connecting-and-authentication.md)
4. [SQL Database in Microsoft Fabric](sql-database-in-fabric.md)

## Learning outcomes

- Choose between SQL Server, Azure SQL Database, Azure SQL Managed Instance, SQL Server on Azure VM, and SQL database in Fabric for a scenario.
- Explain vCore vs DTU, General Purpose vs Business Critical vs Hyperscale, serverless and elastic pools.
- Explain Managed Instance **update policies** and why feature availability differs between platforms.
- Connect with Microsoft Entra authentication (passwordless).
